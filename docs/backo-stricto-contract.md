For Stricto reference, see the [Stricto documentation](https://stricto.readthedocs.io/en/latest/readme.html).

For Backo reference, see the [Backo documentation](https://backo.readthedocs.io/en/latest/readme.html).

Fronto will provide from start generic web components for all the basic types defined by Stricto.

When a running Backo app is available, Fronto CLI tool will be used to generate the specialized web components that will map the the data models exposed by Backo application routes. These web components are compound by the basic web components that wrap the basic Stricto types.
